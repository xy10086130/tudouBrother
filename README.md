# 土豆兄弟

一款使用 **Cocos Creator + TypeScript** 开发的仿土豆兄弟项目。

玩家在游戏中可以选择角色和武器，进入战斗场景后通过移动、射击、拾取补给和升级属性，尽可能在一波又一波的敌人攻势中生存下来。

---

## 项目简介

本项目包含了完整的游戏流程：

- 启动界面
- 角色/武器选择界面
- 游戏主场景
- 敌人波次生成
- 补给掉落与拾取
- 升级系统
- 音效与背景音乐
- 敌人对象池与补给对象池
- 敌人群聚 AI

项目整体采用 **事件驱动 + 单例管理 + 对象池** 的结构，便于后续扩展。
剩余进度：
  -1.武器种类扩展：目前只写了拳头和激光枪
  -2.界面ui完善
  -3.enemy种类扩展
  -....

## 核心功能

### 1. 场景流程
- `LoadingScene`：游戏启动界面
- `ChooseMgr`：角色与武器选择界面
- `GameSceneMgr`：游戏主场景控制
- 结算/结束场景：玩家死亡后跳转

### 2. 玩家系统
- 玩家移动控制：`W / A / S / D`
- 玩家属性管理：生命、攻击、速度、护甲、闪避、暴击、幸运等
- 升级后属性自动应用到角色
- 支持生命恢复、生命偷取、闪避等战斗机制

### 3. 武器系统
- 支持多种武器
- 武器选择在角色选择界面完成
- 武器属性可随升级变化
- 子弹具备伤害、穿透等能力

### 4. 敌人系统
- 敌人按波次生成
- 不同敌人拥有不同属性
- 支持近战追踪、远程射击等行为
- 支持敌人群聚/结伴生成
- 使用对象池提升性能

### 5. 波次系统
- 游戏开始后进入倒计时
- 按波次生成敌人
- 每一波结束后进入升级界面
- 玩家选择升级后进入下一波

### 6. 补给系统
- 敌人死亡后随机掉落补给
- 补给可提供金币和经验
- 使用对象池管理补给节点

### 7. 音频系统
- 背景音乐播放
- 按钮悬停/点击音效
- 受击、升级等效果音

## 操作说明

### 游戏操作
- **W / A / S / D**：控制角色移动
- 角色与武器选择：在选择界面通过点击完成
- 游戏中拾取补给、击败敌人获取经验和金币
- 波次结束后进入升级界面，选择属性强化

### 界面操作
- **Start**：开始游戏
- **Exit**：退出游戏
- **Back**：返回上一界面

---

## 技术特点

- **TypeScript** 编写
- 基于 **Cocos Creator**
- 采用 **单例模式** 管理核心系统
- 使用 **事件总线（EventMgr）** 解耦模块
- 使用 **对象池（NodePool）** 优化性能
- 敌人生成与补给掉落均采用配置驱动
- 支持读取 JSON 配置文件动态生成数据

## 核心模块说明

### 1. 配置管理
`Config.ts`

负责管理：

- 敌人配置
- 补给配置
- 武器配置
- 升级配置
- 经验配置
- 波次配置
- 武器描述配置

同时定义了大量全局事件与碰撞组。

### 2. 玩家数据
`PlayerData.ts`

负责管理玩家的基础属性与战斗属性，包括：

- 生命值
- 经验
- 金币
- 攻击力
- 攻击速度
- 暴击率
- 护甲
- 闪避
- 幸运等

### 3. 敌人管理
`EnemyFactory.ts`

负责：

- 敌人对象池初始化
- 敌人生成
- 敌人死亡回收
- 敌人出现特效与死亡特效
- 群体生成逻辑

### 4. 波次管理
`WaveMgr.ts`

负责：

- 波次切换
- 敌人生成间隔控制
- 波次倒计时
- 波次结束判断

### 5. 游戏主场景管理
`GameSceneMgr.ts`

负责：

- 游戏启动流程
- UI 初始化
- 玩家血量/经验/金币显示
- 波次 UI 更新
- 升级界面显示与关闭
- 玩家死亡后的场景跳转
